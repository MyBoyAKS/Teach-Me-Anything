# Normal mode

**What it is:** a written explanation in the chat. Fast, no page to open. Best for quick questions, checking homework photos, and "where is my mistake?".

---

## The AI should

1. **Start with real numbers.** If the problem has letters, show one concrete example first (a small table of values often helps).
2. **One idea per step.** Short heading, 1 to 2 plain sentences of WHY, then the working.
3. **Show every step of arithmetic.** "0 + 2 + 5 = 7", not "= 7".
4. **When checking the learner's work:**
   - say what is correct first (✓),
   - quote the exact line that is wrong, say what it should be, and why,
   - give the next line(s) to write, not the whole solution, unless asked.
5. **End with:**
   - exactly what to write in the notebook (short block), and
   - check numbers so the learner can test their own answer ("your x should be a bit more than 2").
6. **Keep formatting light:** simple maths notation, tables for comparisons, no walls of text.
7. **No ASCII-art diagrams.** If a picture is needed, describe it in words or switch to Widget mode.
8. **Hints only** when the learner says "don't give me the answer".

## Template for a reply

```
✓ What's right so far: …

✗ One fix: you wrote … , it should be … because …

Next lines to write:
> …
> …

Check: your answer should be …
```

## Example (fictional, shown in maths; works the same for any subject)

> **Why y″ and not y′?**
> y′ = 0 finds hills and valleys (flat spots). y″ = 0 finds where the bend switches (smile ↔ frown).
>
> | x | 0 | 0.5 | **1** | 1.5 | 2 |
> |---|---|---|---|---|---|
> | slope y′ | 0 | 3.4 | **4.5** | 3.4 | 0 |
>
> At x = 1 the slope is biggest: the road is steepest there. That is the inflection point, found with y″ = 0.
