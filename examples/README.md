# Examples

Download a file and open it in any browser (double-click). They load MathJax and a font from public CDNs, so be online.

| File | What it shows |
|---|---|
| `how-to-use.html` | A 50-second walkthrough: copy the prompt, paste it into any AI, fill in your profile, ask with a mode, or upload the files once. |
| `ultra-puzzle-demo.html` | An Ultra-mode "pick the next step" puzzle: a wrong pick gives a hint, the right pick continues. |
| `widget-demo-basic.html` | Solving 2x + 3 = 7. Terms slide and morph while two lines on a graph move but always cross at x = 2. |
| `widget-demo-pointers.html` | A real Calculus homework step (finding a and b for an inflection point). Highlight boxes and arrows point at exactly the term being explained, including a curved "substitute here" arrow. |

Both were built with the recipe in [`../TMA_WIDGET_ENGINE.md`](../TMA_WIDGET_ENGINE.md).
